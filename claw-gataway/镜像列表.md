# claw-gataway 镜像列表

本文档列出 `claw-gataway` 部署涉及的全部容器镜像（共 **13** 个），含地址与用途。默认版本以 `k8s/install.sh`、`k8s/storage/config.sh`、`k8s/storage/helm/seaweedfs-csi-driver/values.yaml` 为准。

| # | 镜像地址 | 用途 |
|---|----------|------|
| 1 | `registry-public.lenovo.com/newapi/new-api:new-api-v1` | New API 网关与管理后台 |
| 2 | `registry-public.lenovo.com/newapi/postgres:15` | PostgreSQL 数据库 |
| 3 | `registry-public.lenovo.com/newapi/redis:latest` | Redis 缓存 |
| 4 | `registry-public.lenovo.com/newapi/new-api:vllmopenai0.22` | vLLM 模型推理服务（OpenAI 兼容 API） |
| 5 | `registry-public.lenovo.com/newapi/new-api:seaweedfs430` | SeaweedFS 宿主机服务（Master / Volume / Filer / S3 Gateway） |
| 6 | `registry-public.lenovo.com/earth_system/seaweedfs-wrapper:3.71` | SeaweedFS Wrapper 代理层（可选组件） |
| 7 | `registry-public.lenovo.com/newapi/new-api/seaweedfs-csi-driver:v1.4.17` | SeaweedFS CSI 插件（Controller + Node） |
| 8 | `registry-public.lenovo.com/newapi/new-api/seaweedfs-mount:v1.4.17` | SeaweedFS FUSE 挂载服务（Mount DaemonSet） |
| 9 | `registry-public.lenovo.com/newapi/new-api/csi-provisioner:v3.5.0` | CSI Sidecar：动态创建 PersistentVolume |
| 10 | `registry-public.lenovo.com/newapi/new-api/csi-resizer:v1.8.0` | CSI Sidecar：卷在线扩容 |
| 11 | `registry-public.lenovo.com/newapi/new-api/csi-attacher:v4.3.0` | CSI Sidecar：卷挂载协调 |
| 12 | `registry-public.lenovo.com/newapi/new-api/csi-node-driver-registrar:v2.8.0` | CSI Sidecar：向 kubelet 注册驱动 |
| 13 | `registry-public.lenovo.com/newapi/new-api/livenessprobe:v2.10.0` | CSI Sidecar：插件存活探针 |

## 说明

- **#1–#3**：`install.sh` 一键部署 K8s 平台时必用。
- **#4**：`DEPLOY_VLLM=true` 时通过 Helm 部署 vLLM。
- **#5–#6**：`DEPLOY_STORAGE=true` 时在宿主机以 Docker + systemd 运行，与 K8s 独立。
- **#7–#13**：SeaweedFS CSI Driver，需单独 `helm install`（`install.sh` 默认不部署）；7 个镜像为一组，在集群内挂载 SeaweedFS 存储卷。

## 一键拉取

```bash
images=(
  registry-public.lenovo.com/newapi/new-api:new-api-v1
  registry-public.lenovo.com/newapi/postgres:15
  registry-public.lenovo.com/newapi/redis:latest
  registry-public.lenovo.com/newapi/new-api:vllmopenai0.22
  registry-public.lenovo.com/newapi/new-api:seaweedfs430
  registry-public.lenovo.com/earth_system/seaweedfs-wrapper:3.71
  registry-public.lenovo.com/newapi/new-api/seaweedfs-csi-driver:v1.4.17
  registry-public.lenovo.com/newapi/new-api/seaweedfs-mount:v1.4.17
  registry-public.lenovo.com/newapi/new-api/csi-provisioner:v3.5.0
  registry-public.lenovo.com/newapi/new-api/csi-resizer:v1.8.0
  registry-public.lenovo.com/newapi/new-api/csi-attacher:v4.3.0
  registry-public.lenovo.com/newapi/new-api/csi-node-driver-registrar:v2.8.0
  registry-public.lenovo.com/newapi/new-api/livenessprobe:v2.10.0
)
for img in "${images[@]}"; do docker pull "$img"; done
```
